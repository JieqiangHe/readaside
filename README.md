# ocrp

**o**ld · **c**lean · **r**ead · **p**aper — a small PDF reader I keep for myself: drop in a paper, select a passage, get the translation, keep the note. Made for going through the literature fast, and for the times when I would rather slow down and read a good paper closely, the old way.

**Live: https://jieqianghe.github.io/readaside/**
