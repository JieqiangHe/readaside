# ocrp

A single-file PDF reader with side-by-side AI translation (DeepSeek, your own key). Live at https://jieqianghe.github.io/ocrp/ (GitHub Pages serves `main`). Forked from an older Chinese 12-provider app and rewritten all-English, minimal. ocrp = old, clean, read, paper: a personal tool for going through papers fast, and for the occasional slow close read of a good one. Renamed miniread → readaside → ocrp on 2026-10-31; `.miniread.json`/`.readaside.json` files, PDF annotations and attachments by those names are still read.

## Repo rules

- The whole app is one file, `index.html`. The repo mirrors minisvg's layout: `index.html`, `README.md`, `LICENSE` (GPL-3.0, same as minisvg), `.gitignore`, `CLAUDE.md`. Do not add test files or other folders.
- Plain JavaScript, no framework, no build step. Only external dependency: pdf.js 3.11.174 from cdnjs (viewer + worker); it must keep working as a local/static page. pdf-lib 1.17.1 (MIT) is inlined at the end of `index.html` as `<script type="text/plain" id="mPlib">` (user's OK, 2026-10-31; ~525 KB, run by `plib()` on first Save PDF) — don't edit inside it; keep code above it.
- Commit to `main` and push to GitHub (remote is SSH: `git@github.com:JieqiangHe/ocrp.git`) after each change — standing OK from the user (2026-10-07: everything in the folder goes up, only .DS_Store stays ignored).
- UI text, tooltips, messages and README are English only. Never leave Chinese in the app.
- Code style: dense and short, section comments `// ---------- name ----------`, match the surrounding one-liner style. Don't refactor unasked.
- README is short: the ocrp name spelled out, a sentence or two on what it is for, and the `**Live: ...**` line.
- UI philosophy: minimal chrome, beUI's shapes (hairline `--line` borders, glass `--glass` selection bar and menus, 8–14 px radii) over a calm eye-friendly palette (user's request, 2026-10-31): warm low-saturation neutrals (`#f4f3ef` bars / `#efeee9` side / `#e7e5df` viewer light, `#1d1c1a`/`#201f1d`/`#181716` dark), a muted sage accent `--onb`, no gradients anywhere; notes keep muted amber (`--nt`) / violet (`--cm`); the chat send button is solid `--fg`. The empty viewer shows nothing — no text or filler in the middle. **The user has ADHD (2026-10-31): keep visible controls to the absolute minimum, gather one-off controls in the Settings sheet, and never add chrome or filler without asking.** There is no composer any more (removed 2026-10-31): input is PDF selection only; Auto is a checkbox in the settings sheet's Translating card. There is also no bottom status bar and no notes pane (both removed 2026-10-31): the top bar is svguest-style **words, not buttons** — `Open`, `Notes ▾` (Save notes ⌘S / Save PDF with comments / Clear all), `Settings` — then the tab strip, then the status message and Undo as dim text on the right. **While reading the bar auto-hides** (user's request, 2026-10-31: no visible buttons while reading papers): `#mBar` is a fixed overlay and `body.read` slides it up with `translateY(-100%)`; `barOn()` shows it when the pointer is within 14 px of the top edge, `barOff()` hides it when the pointer is over the viewer, thumbnails or note cards (or a wheel turns over the viewer). Page, zoom, theme, thumbnails and the ? shortcuts live in Settings › View; reading is keyboard-first. First/last page are Home/End only.

## Architecture (names in index.html)

- Helpers: `$(id)`, `V` = `#mView`, `ls(k,v)` = localStorage get/set, `el/btn/msg/nl`.
- AI config (DeepSeek only; GLM, its relay and its JSON fallback were removed at the user's request, 2026-10-31): `URL0`, `MODELS`; storage `mrdDs<Key|Model|Ep>`, global `mrdThink`, `mrdLang`, `mrdPrompt`, `mrdAuto`, `mrdThumbs`, `mrdTheme`, notes `mrdN:<fingerprint>`. Settings live in `#mConn` — a centered floating sheet (max 560 px) over a dim backdrop (‹, Esc or a click outside closes it; opening it hides the top bar); `cfg(on)` toggles it, three cards: DeepSeek (Model/Think/Key/URL), Translating (Into + the Auto checkbox), View (page, zoom, theme, thumbnails, shortcuts — the old toolbar widgets, `setTh`/`setTheme` set those buttons' text). `mThink`/`mLang` stay hidden selects driven by `seg(id)`. `aiLoad()` fills Model/Key/URL.
- Notes UI: no separate pane — cards float OVER the viewer, each right below its passage (2026-10-31, user's idea; immersive-translate style). `#mNotes` is an overlay on `#mViewWrap` (`pointer-events:none`, `.item` gets `pointer-events:auto`), synced to scroll with `NS.style.transform=translateY(-scrollTop)`; there are no connector lines — adjacency ties a card to its highlight. Every card is a `.item` (`.t` translation, `.c` comment; `shell(o,label)` builds header dot/kind/`.md`/actions `.ia`). Note `o={k,t,rs,fy,out,m,d,chat,el,ac,qc}`: `rs` = merged line rects `[page,x,y,w,h]` in PDF units from `rects(range)` at mouseup (`selA`). `want(o)` anchors a card below its last line on its first page (or `fy*docH` for anchor-less notes); `frame()` (rAF via `sched()`) sets `left/width` from the page and eases `top` in content coordinates toward the anchor, pushing overlapping cards down (active `nAct` pinned first); `#mView` gets bottom padding so the last card is reachable. `pick(o)` activates and scrolls the passage into view only when off-screen. Chat UI (`.cv`, `.q`/`.r`, input `.ci`) lives under translations as before. Wheel over a card forwards to the viewer.
- Selection bar `#mSelT` (Translate / Comment) appears under a PDF selection; with Auto the translation already started, so only Comment shows. `comment(t,rs,sv)`: textarea `.ce`, autosaved, an empty one is removed on blur.
- `translate(t,rs,sv)`: each call is its own note with its own AbortController (Stop/Copy/Retry/× in `.ia`); requests run side by side; `nLast` owns the status line. `chatUI(o)` adds the Q&A under a finished translation (`.cv`, `.q`/`.r`, input `.ci`, shown when the card is active or has turns); `chat()` sends passage + translation + earlier turns, stores `o.chat`.
- Clear (`#mClr`, now a menu item in `Notes ▾`, `clrAll`): one click removes all notes and hides the PDF's own markup annotations (`annOff`, pages/thumbnails re-render with `AnnotationMode.DISABLE`; `annN` counted in the background); Undo `#mUndo` (dim word, top-bar right) for 10 s. An ocrp export (has one of the `ATT`/`AT0`/`AT1` attachments) opens with `annOff` so its highlights aren't drawn twice.
- Motion and comfort: cards ease to their places in `frame(now)` (time-based, `o.y` toward the target, re-`sched()` until settled; snaps with reduced motion, `RM`); cards fade in (`mIn`) and out (`fade()`, `.out`); menus/selection bar pop (`mPop`), the settings sheet slides (`mSheet`), theme changes cross-fade via `document.startViewTransition`. A global `prefers-reduced-motion` rule turns all animation off. The PDF itself is never recoloured in dark mode (user's request, 2026-10-31): only the interface changes. Card text is 13 px / 1.65.
- Saving notes: autosaved per PDF in localStorage `mrdN:<pdf.fingerprints[0]>` (`nsave` after each translation, ×, Clear; `nload` in `openPdf`). Save button / ⌘S (`nfile`) writes `<name>.ocrp.json` `{ocrp:1,pdf,fp,notes:[{t,rs,fy,out,m}]}` (the older `{readaside:1}` and `{miniread:1}` markers are still accepted): Chrome/Edge via `showSaveFilePicker` starting in the PDF's folder (`pdfH` from `showOpenFilePicker` or the drop's `getAsFileSystemHandle`) and rewriting the same file (`jsH`); Safari/Firefox download it. Open…/drop take a PDF and its JSON together (`openFiles`); restored notes go through `translate(t,rs,sv)` without a request.
- Save PDF (`npdf`): pdf-lib run from the inlined `#mPlib` on first use (`plib`), works on `pdf.getData()`; one Highlight annotation per note and page (QuadPoints via `viewport.convertToPdfPoint`, `T:'ocrp'`, amber translations / violet comments, text = translation + chat or comment as `Contents`); earlier annotations by any of the names (`AU` = `miniread`/`readaside`/`ocrp`) and the attachments are removed first, and after Clear (`annOff`) every markup annotation (`MK`). Notes JSON attached as `ATT` (`ocrp-notes.json`; `AT0`/`AT1` are the older `readaside-notes.json`/`miniread-notes.json`, still read and removed). `openPdf` restores from localStorage first, else from that attachment. `keep()` is the shared save-dialog/download path.
- `ask(model,msgs,myAc,ui)` is the single request path (svguest's `call()` minus the GLM routes): body with `thinking` + `reasoning_effort`; SSE lines parsed by `on()` (`j.error` → throw, `delta.reasoning_content` → `ui.think`, `delta.content` → `ui.text`, `finish_reason:'length'` → `cut`); `apiMsg()` decodes JSON error bodies with `[code]`.
- Document tabs (svguest's pattern, 2026-10-31): the ACTIVE pdf lives in the globals (`pdf, pdfName, pdfH, jsH, scale, annOff, annN, N, curN`); background tabs hold snapshots in `TABS[TI]` (plus `st` scrollTop and `notes:N.slice()` — the note objects keep their detached card elements). `tabHold()` snapshots + detaches (cards out of `#mNotes`, pages/thumbs/observers cleared); `tabShow(i)` restores globals, reattaches cards, `layout()` rebuilds pages and restores `scrollTop`. `tabFresh()` (reuse an empty tab or push, `TN` flags a push whose open may fail → `tabBack()` to `TP`), `tabGo/tabClose` (close saves that tab's notes via `nsaveTab`, aborts its controllers, destroys its pdf; last tab resets in place), `tabUI()` rebuilds `#mTabs` only when its key changes. Strip shows from two tabs (`body.multi`), max `TMAX=10`; names lose `.pdf`, middle-click closes. A translation finishing on a background tab updates its card but its autosave lands when that tab is next touched or closed.
- PDF: `open/openPdf/layout/draw/zoom/fit/goto/cur`. `gen` cancels stale layouts; `layP` is the last layout promise (`goto` retries through it when the page div isn't built yet); pages lazy-render via IntersectionObserver (800px margin), thumbnails (96px wide) via `tgen/tobs/tdraw`. The `--scale-factor` CSS var must stay on `.page` (pdf.js text layer needs it). Scale is clamped to 0.1–8; Ctrl-wheel zoom is debounced 60 ms (`wzT`). `openPdf` no longer destroys the previous pdf (it may live in another tab); only `tabClose` destroys.
- Keys: `?` help, `+`/`-`/`0` zoom, `←`/`→` page step, `↑`/`↓`/`Space` scroll, `Home`/`End` first/last. The handler skips events targeted at inputs/buttons.
- Selection: `mouseup` on the viewer → dehyphenate `-\n` before lowercase → collapse whitespace → `lastSel` dedupe → auto-translate if `#mAuto`. Drag&drop is handled at document level and only for files (PDF + notes JSON); `translate(txt)` gets its text from the selection, there is no composer.
- Actions: `data-a` buttons mapped in the object `A`; theme via `setTheme` + `mrdTheme`, with an inline `<script>` applying it before paint.

## Pitfalls

- `#mViewWrap [hidden]{display:none!important}` keeps hidden cards and the settings sheet hidden against the overlay's rules; `#mSelT [hidden]` likewise. Inline `on*` handlers must not return `false` (it cancels the event) — wrap arrow bodies in braces.
- The word-count line contains literal `\uXXXX` ranges; those can't be matched through the Edit tool (escapes get decoded). Edit that line via python or split edits around it.
- pdf.js is pinned to 3.11.174: v4 replaced `pdfjsLib.renderTextLayer` with a `TextLayer` class — don't upgrade casually.
- The repo has to stay public: Pages is a branch deploy from `main`, and a private repo drops the site (it went dark 2026-10-10 that way and was re-enabled 2026-10-31).
- DeepSeek receives both `thinking:{type:'enabled'}` and `reasoning_effort`; fine with the current models, revisit if the API rejects them.
- The card classes reuse svguest's chat names (`wt/sh/tm/tk/th/er/dim`); keep them in sync when svguest changes. `MARK` is ocrp's own waiting mark (the translate-arrow glyph, user's request 2026-10-31; it breathes with `mTr`, 17×13 px), not svguest's house.

## Testing

- No test suite. Syntax-check every inline `<script>` block with node (`~/.local/bin/node`, `new Function(src)` per block). `~/.local/bin/node`/`git` are plain symlinks into the mamba envs (replacing `micromamba run` shims, 2026-10-31 — such shims die on the `~/.cache/mamba/proc` lock under the DSH sandbox; don't wrap again, gh/tmux/tree-style links are fine). `/usr/bin/python3` and `osascript` are broken Xcode CLT stubs on this machine — don't use them.
- Static checks in the same node run: id uniqueness, every `$()` reference has an element, every `data-a` button has an `A` entry.
- Visual check: `open index.html`, then ⌘R to reload (the user reviews screenshots; `open` alone does not reload an existing tab).
