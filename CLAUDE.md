# miniread

A single-file PDF reader with side-by-side AI translation (GLM / DeepSeek, your own key). Live at https://jieqianghe.github.io/miniread/ (GitHub Pages serves `main`). Forked from an older Chinese 12-provider app and rewritten all-English, minimal.

## Repo rules

- The whole app is one file, `index.html`. The repo mirrors minisvg's layout: `index.html`, `README.md`, `LICENSE` (GPL-3.0, same as minisvg), `.gitignore`, `CLAUDE.md`. Do not add test files or other folders.
- Plain JavaScript, no framework, no build step. Only external dependency: pdf.js 3.11.174 from cdnjs (viewer + worker); it must keep working as a local/static page. pdf-lib 1.17.1 (MIT) is inlined at the end of `index.html` as `<script type="text/plain" id="mPlib">` (user's OK, 2026-10-31; ~525 KB, run by `plib()` on first Save PDF) — don't edit inside it; keep code above it.
- Commit to `main` and push to GitHub (remote is SSH: `git@github.com:JieqiangHe/miniread.git`) after each change — standing OK from the user (2026-10-07: everything in the folder goes up, only .DS_Store stays ignored).
- UI text, tooltips, messages and README are English only. Never leave Chinese in the app.
- Code style: dense and short, section comments `// ---------- name ----------`, match the surrounding one-liner style. Don't refactor unasked.
- README is one sentence and the `**Live: ...**` line. Keep it that short.
- UI philosophy: minimal chrome, styled after svguest (its palette variables, 6–10 px radii, `.ib` icon buttons, `.seg` segmented controls, `.dd/.menu` dropdowns, settings sheet `#mConn` with cards — user's choice, 2026-10-31). Don't add visible controls or filler text without asking. Toolbar (trimmed 2026-10-31, no app name): thumbnails icon, Open…, ‹ page / N ›, − zoom% + (the % button fits the width), and on the right ? and theme; the status bar holds only messages, Undo and the selection count. First/last page are Home/End only.

## Architecture (names in index.html)

- Helpers: `$(id)`, `V` = `#mView`, `ls(k,v)` = localStorage get/set, `el/btn/msg/nl`.
- AI config: `AI` map (provider → `[default URL, ...models]`); per-provider storage `mrd<Glm|Ds><Key|Model|Ep>`, global `mrdAi`, `mrdThink`, `mrdLang`, `mrdPrompt`, `mrdAuto`, `mrdThumbs`, `mrdTheme`, `mrdGlmRelay`, notes `mrdN:<fingerprint>`. Settings live in the sheet `#mConn` (gear `#mCfgB` or the model pill `#mMd`, Esc/‹ closes; `cfg(on)`); `mProv`/`mThink`/`mLang` stay hidden selects driven by `seg(id)`. `aiLoad()` refills Model/Key/URL on provider switch; `mdUI()` updates the pill (ring = no key).
- GLM relay (mirrors svguest): BigModel rejects browser CORS from GitHub Pages, so GLM goes through svguest's Cloudflare Worker `RLY` (`/glm/standard`, `/glm/coding`, mapped from the official URLs in `RLYR`). Checkbox in Settings, shown only when `rlyOk()` (origin `https://jieqianghe.github.io` and provider GLM), on by default; fetch with `credentials:'omit'`, `redirect:'error'`; any other URL errors out. The Worker's `ORIGINS` must keep listing that origin.
- Notes UI (mind-map style): every note is a card (`.item.t` translation, `.item.c` comment; `shell(o,label)` builds header dot/kind/`.md`/actions `.ia`) in the right lane `#mLane`/`#mNotes`, linked by an SVG line (`#mLink`, `g.t`/`g.c`) to a highlight (`.hl`, `.hl.c` blue, sized with `calc(var(--scale-factor)*…)`). Note `o={k,t,rs,fy,out,m,d,chat,el,ac,qc}`: `rs` = merged line rects `[page,x,y,w,h]` in PDF units from `rects(range)` at mouseup (`selA`), null for pasted text (then `fy` places it). `frame()` (rAF via `sched()`) aligns the active note `nAct` to its anchor and pushes the others so cards never overlap, pads `#mView` bottom, draws lines (`#mLane` z-index above them). `pick(o)` activates a card without moving it (scrolls the PDF instead). Wheel over the lane scrolls the PDF; opening a PDF clears notes.
- Selection bar `#mSelT` (Translate / Comment) appears under a PDF selection; with Auto the translation already started, so only Comment shows. `comment(t,rs,sv)`: textarea `.ce`, autosaved, an empty one is removed on blur.
- `translate(t,rs,sv)`: each call is its own note with its own AbortController (Stop/Copy/Retry/× in `.ia`); requests run side by side; `nLast` owns the status line. `chatUI(o)` adds the Q&A under a finished translation (`.cv`, `.q`/`.r`, input `.ci`, shown when the card is active or has turns); `chat()` sends passage + translation + earlier turns, stores `o.chat`.
- Clear (`#mClr`, `clrAll`): one click removes all notes and hides the PDF's own markup annotations (`annOff`, pages/thumbnails re-render with `AnnotationMode.DISABLE`; `annN` counted in the background); Undo `#mUndo` in the status bar for 10 s. A miniread export (has `ATT`) opens with `annOff` so its highlights aren't drawn twice.
- Motion and comfort: cards ease to their places in `frame(now)` (time-based, `o.y` toward the target, re-`sched()` until settled; snaps with reduced motion, `RM`); cards fade in (`mIn`) and out (`fade()`, `.out`); menus/selection bar pop (`mPop`), the settings sheet slides (`mSheet`), theme changes cross-fade via `document.startViewTransition`. A global `prefers-reduced-motion` rule turns all animation off. The PDF itself is never recoloured in dark mode (user's request, 2026-10-31): only the interface changes. Card text is 13 px / 1.65.
- Saving notes: autosaved per PDF in localStorage `mrdN:<pdf.fingerprints[0]>` (`nsave` after each translation, ×, Clear; `nload` in `openPdf`). Save button / ⌘S (`nfile`) writes `<name>.miniread.json` `{miniread:1,pdf,fp,notes:[{t,rs,fy,out,m}]}`: Chrome/Edge via `showSaveFilePicker` starting in the PDF's folder (`pdfH` from `showOpenFilePicker` or the drop's `getAsFileSystemHandle`) and rewriting the same file (`jsH`); Safari/Firefox download it. Open…/drop take a PDF and its JSON together (`openFiles`); restored notes go through `translate(t,rs,sv)` without a request.
- Save PDF (`npdf`): pdf-lib run from the inlined `#mPlib` on first use (`plib`), works on `pdf.getData()`; one Highlight annotation per note and page (QuadPoints via `viewport.convertToPdfPoint`, `T:'miniread'`, yellow translations / blue comments, text = translation + chat or comment as `Contents`); earlier `miniread` annotations and `ATT` attachments are removed first, and after Clear (`annOff`) every markup annotation (`MK`). Notes JSON attached as `ATT` (`miniread-notes.json`). `openPdf` restores from localStorage first, else from that attachment. `keep()` is the shared save-dialog/download path.
- `ask(model,msgs,myAc,ui)` is the single request path (svguest's `call()`): same body for both providers (`thinking` + `reasoning_effort`); SSE lines parsed by `on()` (`j.error` → throw, `delta.reasoning_content` → `ui.think`, `delta.content` → `ui.text`, `finish_reason:'length'` → `cut`). GLM falls back to `stream:false` when fetch throws TypeError or the reply is not `text/event-stream` — `glmJ` remembers such URLs, and the JSON reply is read from `choices[0].message`; relay errors get their own messages; `apiMsg()` decodes JSON error bodies with `[code]`.
- PDF: `open/openPdf/layout/draw/zoom/fit/goto/cur`. `gen` cancels stale layouts; `layP` is the last layout promise (`goto` retries through it when the page div isn't built yet); pages lazy-render via IntersectionObserver (800px margin), thumbnails (96px wide) via `tgen/tobs/tdraw`. The `--scale-factor` CSS var must stay on `.page` (pdf.js text layer needs it). Scale is clamped to 0.1–8; Ctrl-wheel zoom is debounced 60 ms (`wzT`).
- Keys: `?` help, `+`/`-`/`0` zoom, `←`/`→` page step, `↑`/`↓`/`Space` scroll, `Home`/`End` first/last. The handler skips events targeted at inputs/buttons.
- Selection: `mouseup` on the viewer → dehyphenate `-\n` before lowercase → collapse whitespace → `lastSel` dedupe → auto-translate if `#mAuto`. Drag&drop is handled at document level and only for files, so text drops into the textarea still work.
- Actions: `data-a` buttons mapped in the object `A`; theme via `setTheme` + `mrdTheme`, with an inline `<script>` applying it before paint.

## Pitfalls

- `#mRight [hidden]{display:none!important}` keeps hidden rows hidden against the panel's display rules; `#mSelT [hidden]` likewise. Inline `on*` handlers must not return `false` (it cancels the event) — wrap arrow bodies in braces.
- The word-count line contains literal `\uXXXX` ranges; those can't be matched through the Edit tool (escapes get decoded). Edit that line via python or split edits around it.
- pdf.js is pinned to 3.11.174: v4 replaced `pdfjsLib.renderTextLayer` with a `TextLayer` class — don't upgrade casually.
- DeepSeek receives both `thinking:{type:'enabled'}` and `reasoning_effort`; fine with the current models, revisit if the API rejects them.
- The card classes reuse svguest's chat names (`wt/sh/tm/tk/th/er/dim`), the `MARK` waiting icon and `ask()` = svguest's `call()` fallbacks; keep them in sync when svguest changes.

## Testing

- No test suite. Syntax-check every inline `<script>` block with node (`~/.local/bin/node`, `new Function(src)` per block). `/usr/bin/python3` and `osascript` are broken Xcode CLT stubs on this machine — don't use them.
- Static checks in the same node run: id uniqueness, every `$()` reference has an element, every `data-a` button has an `A` entry.
- Visual check: `open index.html`, then ⌘R to reload (the user reviews screenshots; `open` alone does not reload an existing tab).
