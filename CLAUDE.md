# ocrp

A single-file PDF reader with side-by-side AI translation (DeepSeek, your own key). Live at https://jieqianghe.github.io/ocrp/ (GitHub Pages serves `main`). Forked from an older Chinese 12-provider app and rewritten all-English, minimal. ocrp = old, clean, read, paper: a personal tool for going through papers fast, and for the occasional slow close read of a good one. Renamed miniread → readaside → ocrp on 2026-10-31; `.miniread.json`/`.readaside.json` files, PDF annotations and attachments by those names are still read.

## Repo rules

- The whole app is one file, `index.html`. The repo mirrors minisvg's layout: `index.html`, `README.md`, `LICENSE` (GPL-3.0, same as minisvg), `.gitignore`, `CLAUDE.md`. Do not add test files or other folders.
- Plain JavaScript, no framework, no build step. Only external dependency: pdf.js 3.11.174 from cdnjs (viewer + worker); it must keep working as a local/static page. pdf-lib 1.17.1 (MIT) is inlined at the end of `index.html` as `<script type="text/plain" id="mPlib">` (user's OK, 2026-10-31; ~525 KB, run by `plib()` on first Save PDF) — don't edit inside it; keep code above it.
- Commit to `main` and push to GitHub (remote is SSH: `git@github.com:JieqiangHe/ocrp.git`) after each change — standing OK from the user (2026-10-07: everything in the folder goes up, only .DS_Store stays ignored).
- UI text, tooltips, messages and README are English only. Never leave Chinese in the app.
- Code style: dense and short, section comments `// ---------- name ----------`, match the surrounding one-liner style. Don't refactor unasked.
- README is short: the ocrp name spelled out, a sentence or two on what it is for, and the `**Live: ...**` line.
- UI philosophy: minimal chrome, Claude's warm palette (user's request, 2026-10-31, after the svguest gray look read as too white): cream light mode (`#faf9f5` cards / `#f0eee6` bar and side / `#e8e5dc` viewer) with near-black warm text `#141413`, warm dark mode (`#2a2926` cards / `#1f1e1d` bar / `#141413` viewer) with `#f5f4ef` text, terracotta accent `--onb:#c96442`/`#e08a6a`, warm hairline `--line`, 6 px radii on controls and 8–10 px on panels, no glass, no gradients, no press-scale; notes use amber (`--nt`) and blue (`--cm`) highlights; PDF text selection is the terracotta tint. **The user has ADHD (2026-10-31): keep visible controls to the absolute minimum, gather one-off controls in the Settings sheet, and never add chrome or filler without asking.** There is no composer any more (removed 2026-10-31): input is PDF selection only; Auto is a checkbox in the settings sheet's Translating card. **There is no top bar at all** (removed 2026-11-01, user's request: nothing above the paper): the tab strip went with it — tabs are reached through the `K` palette and `[`/`]` — and Undo is a small pill at the bottom for its ten seconds (`#mUndo`); the old auto-hide machinery (`body.read`, `barOn/barOff`, `#mTabs`, `tabUI()` markup) is gone, `tabUI()` is a no-op. Save is `⌘S`, a commented PDF `⌘⇧S`, clear everything `⌘⇧X`; **no status message** (`msg()` is a no-op; translation errors still show inside their card); **no Open or Settings words** (`O` (or `⌘O`) or a drop opens, `,` opens Settings). The empty viewer shows one card copied from svguest's What's-new dialog (`#mHint .wcard`, user, 2026-11-01): a 160 px gradient hero (`#mHint .wh`) with a “shortcuts” chip top-left and a small mocked reader sat at the hero's bottom (`align-items:end`, 14 px padding) so it clears the chip—white page with an amber line plus a cream card on its right (`#mHint .wp`) — the mock is a 4.6 s loop (user, 2026-11-01): the page lines write in (`mHero`), the amber passage grows left to right (`mSel`), the cream card slides in from the right (`mCard`), then the scene fades and starts again, all off under `prefers-reduced-motion`; the body (`#mHint .wb`) is the title `ocrp` + `old, clean, read, paper`, then a single column of 10 rows, each 30 px — 15 px stroke icon, action name, and small right-aligned keycaps (`#mHint li kbd`, `--side` with a hairline) for O / ⌘S / ⌘⇧S / K / ←→ / +−0 / F / T / H / , (keycaps carry `data-k`, and on Windows/Linux `MAC` is false so ⌘/⇧/↵ are rewritten to Ctrl/Shift/Enter at load) — no “All shortcuts” row since the footer already points at `?`; the footer (`#mHint .wf`) holds “Press ? to bring this card back · GitHub ↗” (the user's profile, https://github.com/JieqiangHe) and a dark “Got it” (`#mHintOk` → `hintOff`); there is no shortcuts dialog (removed 2026-11-01: the card is the shortcut list, `?` calls `hintOn()` and `body.ask` lets it show over an open PDF; Enter, O, Esc, a wheel over the card, a click outside it, opening a PDF and switching tabs all put it away — a card left up covers the middle of the screen and swallows the wheel, which read as “the PDF will not scroll”, 2026-11-01). The one-time DeepSeek key prompt (`#mKeyFirst`) sits above the card while no key is stored. Enter or O calls `hintOff()` (session) and the card goes; it is a `position:fixed` overlay (`#mHint`, z-index 4) so it centres in the window, and `body.pdf` hides it as soon as a PDF is open. Settings opens with <kbd>,</kbd> and holds only DeepSeek and Translating (the View card was removed at the user's request, 2026-10-31); <kbd>T</kbd> toggles the light/dark theme and <kbd>H</kbd> the thumbnails, page and zoom are keyboard/wheel only (`curN` is the page state, there is no page input). Reading is keyboard-first. First/last page are Home/End only.

## Architecture (names in index.html)

- Helpers: `$(id)`, `V` = `#mView`, `SC` = `#mMain` (the scroller), `ls(k,v)` = localStorage get/set, `el/btn/msg/nl` (`msg()` is a no-op since 2026-11-01).
- AI config (DeepSeek only; GLM, its relay and its JSON fallback were removed at the user's request, 2026-10-31): `URL0`, `MODELS`; storage `mrdDs<Key|Model|Ep>`, global `mrdThink`, `mrdLang`, `mrdPrompt`, `mrdAuto`, `mrdThumbs`, `mrdTheme`, notes `mrdN:<fingerprint>`. Settings live in `#mConn` — a centered floating sheet (max 560 px) over a dim backdrop (‹, Esc or a click outside closes it); `cfg(on)` toggles it (bound to `,`), two cards: DeepSeek (Model/Think/Key/URL) and Translating (Into + the Auto checkbox); the `.seg` segmented control has no track — the chosen segment is a subtle `--btnh` pill (user: a dark track looked heavy). Theme (`T`) and thumbnails (`H`) are keys only; `setTh`/`setTheme` just toggle state. The thumbnail strip **starts hidden every time the app loads and every time a PDF opens** (user, 2026-11-01: `setTh(false)` at load and inside `openPdf`), and nothing is remembered — `mrdThumbs` is gone — so `H` brings it in for that session only. The first-run key prompt is `#mKeyFirst`/`#mKey0`/`#mKeySave` in the empty viewer; saving writes `mrdDsKey` and fills `#mKey`. `mThink`/`mLang` stay hidden selects driven by `seg(id)`. `aiLoad()` fills Model/Key/URL.
- Notes UI: no separate pane — cards float OVER the viewer, right-aligned in a column on the right side, each vertically aligned to the top of its passage (2026-10-31; first below the passage, then the user asked for the right side). Card width is `min(420, 40% of the viewer)` and the column is flush to the right edge, set per frame in `frame()`. `#mNotes` is a borderless sticky column beside `#mView` (`flex:none`; width 0 without cards, `noteW()+32` with — `noteW()` reads `SC.clientWidth` so the column cannot shrink itself), `pointer-events:none` with `.item` back on auto; each card keeps `o.y` in content coordinates but is painted at `o.y - SC.scrollTop` (no container transform — that used to clip cards outside the 100vh column) and `frame()` re-runs on scroll; `if(N.length&&!NS.clientWidth)col()` self-heals a column that never took its width; the page is fitted to the remaining width, so it can never run under the cards even after zooming. The first card added and the last one removed call `col()+fit()` (also `tabShow`, `tabClose` and resize). `#mLink` (SVG overlay on `#mMain`, z-index 5) redraws every frame: a curve from the highlight's right edge to the card's header, amber for translations / blue for comments, 2 px when active, culled when either end is off-screen. Blue comments (`.hl.c`) and amber translations (`.hl`) match the card dots. Every card is a `.item` (`.t` translation, `.c` comment; `shell(o,label)` builds header dot/kind/`.md`/actions `.ia`). Note `o={k,t,rs,fy,out,m,d,chat,el,ac,qc}`: `rs` = merged line rects `[page,x,y,w,h]` in PDF units from `rects(range)` at mouseup (`selA`). `want(o)` anchors a card at the top of its first page's block (or `fy*docH` for anchor-less notes); `frame()` (rAF via `sched()`) eases `top` in content coordinates toward the anchor and pushes overlapping cards down (active `nAct` pinned first); `#mView` gets bottom padding so the last card is reachable. `pick(o)` activates and scrolls the passage into view only when off-screen. Chat UI (`.cv`, `.q`/`.r`, input `.ci`) lives under translations as before. Wheel over a card forwards to the viewer.
- Palette (`K`, 2026-11-01, svguest's command-palette shape at the user's request; plain `K` since 2026-11-01 — like `F`, because the browser keeps `⌘K` for its address bar): `#mK` is a dimmed overlay holding a centred panel (input `#mKq`, a horizontal strip `#mKl`, a `←→ ↵ Esc` hint line); `kBuild()` filters the strip as you type (90 ms debounce on the input); the preview cache `kTh`, `rel()` and `mkThumb()` sit just above the palette section — a recents rewrite once swallowed them and the palette went blank (2026-11-01), so keep them with the palette; `kPaint()` wraps `kDraw()` in a try/catch and prints the failure inside the panel rather than showing an empty strip; each item is a `.kc` card — a 132×185 page preview with the name under it; the strip is bottom-aligned over a soft shelf shadow and every card sits a little low and at 42 % opacity, while the selected one **lifts out of the row** (`translateY(-12px) scale(1.02)`, full opacity, terracotta ring and a deeper shadow) — the user asked for it to feel like pulling a file out of a shelf, the open documents then a hairline `.sp` and the recent ones (32 % opacity, their opening time under the name) — **Open** (`TABS` by `tabNm`, the current tab tagged “current”) — every card starts with a 132×185 first-page preview (`mkThumb()` renders page 1 into a 280 px canvas at open, `kTh` caches it by fingerprint, missing ones render lazily when the palette opens; recents carry their own `thumb` in IndexedDB and show it at 55 % opacity) and **Recent** (dimmer rows with a hollow dot, from IndexedDB `ocrp.recent`: the store is split — `recent` holds metadata (name, time, preview, handle) and `blob` the PDF bytes, so listing never reads megabytes and only a reopen fetches them; `recPut()` keeps the last 8 documents keyed by the fingerprint (a PDF over 40 MB keeps its name, preview and handle but no bytes, and the copy is skipped before it is made), plus the `FileSystemFileHandle` when the browser has the FS Access API — `showOpenFilePicker`/`getAsFileSystemHandle`, i.e. Chrome/Edge — so a recent click asks for read permission and reopens the real file on disk (`openPdf(buf,name,h)`, `h` also becomes `pdfH` so Save notes starts in that folder), falling back to the stored bytes for Safari and moved files; a real path is never exposed to the page, the handle is as close as the web gets; the open tabs are filtered out); arrows wrap (←→ or ↑↓) via `kSel()`, which only moves the ring — no DOM rebuild per key — and the missing previews render one at a time in `kThumbs()`; Enter (or a click) switches a tab or reopens a recent one, Esc, a click on the dim area or a switch closes it; a row's title shows the full file name (the row truncates it) and Recent rows end with when they were opened (`rel()`: just now / N min / N h / N d). **A real filesystem path cannot be shown**: browsers never expose one (the file picker only hands over a `FileSystemFileHandle`, whose `name` is all a page may read), so the handle plus the stored copy are the closest thing — noted again at the user's request 2026-11-01.
- Find (`F`, 2026-11-01: it began on `/`, but `?` is Shift+`/`; a brief `⌘F` never reached the app because Safari keeps that key for its own find bar): `#mFind` is a small fixed bar (input `#mFindQ` + count `#mFindS`); `fScan()` searches every page's `getTextContent()` (cached in `fc`, cleared when a PDF opens) and lists the pages that contain the query; `fGo(±1)` jumps through those pages with `goto()` and, once the page's text layer has rendered, `fMark(tl)` wraps the query in `<mark class="fnd">` inside the text-layer spans (the first is `.on`); `Enter`/`Shift+Enter` step, `Esc` closes and `fUnmark()` restores the spans. Tab switches and opens call `fClose()`.
- Selection bar `#mSelT` (Translate / Comment) appears under a PDF selection; with Auto the translation already started, so only Comment shows. `comment(t,rs,sv)`: textarea `.ce`, autosaved, an empty one is removed on blur.
- `translate(t,rs,sv)`: each call is its own note with its own AbortController (Stop/Copy/Retry/× in `.ia`); requests run side by side; `nLast` owns the status line. `chatUI(o)` adds the Q&A under a finished translation (`.cv`, `.q`/`.r`, input `.ci`, shown when the card is active or has turns); `chat()` sends passage + translation + earlier turns, stores `o.chat`.
- Clear (`clrAll`, `⌘⇧X`): one press removes all notes and hides the PDF's own markup annotations (`annOff`, pages/thumbnails re-render with `AnnotationMode.DISABLE`; `annN` counted in the background); Undo `#mUndo` (dim word, top-bar right) for 10 s. An ocrp export (has one of the `ATT`/`AT0`/`AT1` attachments) opens with `annOff` so its highlights aren't drawn twice.
- Motion and comfort: cards ease to their places in `frame(now)` (time-based, `o.y` toward the target, re-`sched()` until settled; snaps with reduced motion, `RM`); cards fade in (`mIn`) and out (`fade()`, `.out`); menus/selection bar pop (`mPop`), the settings sheet slides (`mSheet`), theme changes cross-fade via `document.startViewTransition`. A global `prefers-reduced-motion` rule turns all animation off. The PDF itself is never recoloured in dark mode (user's request, 2026-10-31): only the interface changes. Card text is 13 px / 1.65.
- Saving notes: autosaved per PDF in localStorage `mrdN:<pdf.fingerprints[0]>` (`nsave` after each translation, ×, Clear; `nload` in `openPdf`). Save button / ⌘S (`nfile`) writes `<name>.ocrp.json` `{ocrp:1,pdf,fp,notes:[{t,rs,fy,out,m}]}` (the older `{readaside:1}` and `{miniread:1}` markers are still accepted): Chrome/Edge via `showSaveFilePicker` starting in the PDF's folder (`pdfH` from `showOpenFilePicker` or the drop's `getAsFileSystemHandle`) and rewriting the same file (`jsH`); Safari/Firefox download it. Open…/drop take a PDF and its JSON together (`openFiles`); restored notes go through `translate(t,rs,sv)` without a request.
- Save PDF (`npdf`): pdf-lib run from the inlined `#mPlib` on first use (`plib`), works on `pdf.getData()`; one Highlight annotation per note and page (QuadPoints via `viewport.convertToPdfPoint`, `T:'ocrp'`, amber translations / blue comments, text = translation + chat or comment as `Contents`); earlier annotations by any of the names (`AU` = `miniread`/`readaside`/`ocrp`) and the attachments are removed first, and after Clear (`annOff`) every markup annotation (`MK`). Notes JSON attached as `ATT` (`ocrp-notes.json`; `AT0`/`AT1` are the older `readaside-notes.json`/`miniread-notes.json`, still read and removed). `openPdf` restores from localStorage first, else from that attachment. `keep()` is the shared save-dialog/download path.
- `ask(model,msgs,myAc,ui)` is the single request path (svguest's `call()` minus the GLM routes): body with `thinking` + `reasoning_effort`; SSE lines parsed by `on()` (`j.error` → throw, `delta.reasoning_content` → `ui.think`, `delta.content` → `ui.text`, `finish_reason:'length'` → `cut`); `apiMsg()` decodes JSON error bodies with `[code]`.
- Document tabs (svguest's pattern, 2026-10-31): the ACTIVE pdf lives in the globals (`pdf, pdfName, pdfH, jsH, scale, annOff, annN, N, curN`); background tabs hold snapshots in `TABS[TI]` (plus `st` scrollTop and `notes:N.slice()` — the note objects keep their detached card elements). `tabHold()` snapshots + detaches (cards out of `#mNotes`, pages/thumbs/observers cleared); `tabShow(i)` restores globals, reattaches cards, `layout()` rebuilds pages and restores `scrollTop`. `tabFresh()` (reuse an empty tab or push, `TN` flags a push whose open may fail → `tabBack()` to `TP`), `tabGo/tabClose` (close saves that tab's notes via `nsaveTab`, aborts its controllers, destroys its pdf; the last tab resets in place and the start card comes back so the empty window is not a dead end), `tabUI()` rebuilds `#mTabs` only when its key changes. Strip shows from two tabs (`body.multi`), max `TMAX=10`; names lose `.pdf`, middle-click closes. A translation finishing on a background tab updates its card but its autosave lands when that tab is next touched or closed.
- Scrolling (2026-11-01, user: the scrollbar should sit at the window's right edge and the reading area should read as one surface): `SC=$('mMain')` is the ONLY scroll container — `#mMain{overflow:auto;align-items:flex-start;background:var(--view)}` — so the scrollbar is at the far right and the page column and card column share one background (no seam). `#mView` is the page column (`flex:1;min-width:max-content`, so high zoom pans horizontally), `#mThumb` and `#mNotes` are `position:sticky;top:0;height:100vh` siblings, and everything that used to read `V.scrollTop/clientHeight/scrollHeight/scrollBy` now reads `SC` (`cur`, `goto`, `zoom`, `pick`, `tabHold/tabShow`, `annHide`, the keyboard scroll, the Ctrl-wheel and the wheel-over-cards handlers); `fit()` subtracts the thumbnail strip and the card column from `SC.clientWidth`, taking the column from `noteW()+32` (never from a stale `NS.clientWidth`) after calling `col()`; every window `resize` refits after a 120 ms debounce, and `openPdf` runs one more `fit()` on the next frame once the column and the scrollbar have settled. Overlays pasted to the viewport are `position:fixed`: `#mLink` (viewport coordinates), `#mSelT`, `#mConn`.
- PDF: `open/openPdf/layout/draw/zoom/fit/goto/cur`, and `tc` caches the sidebar thumbnails as JPEG data URLs by fingerprint+page (capped at 400) so switching back to a tab does not draw them again. `gen` cancels stale layouts; `layP` is the last layout promise (`goto` retries through it when the page div isn't built yet); pages lazy-render via IntersectionObserver (800px margin), thumbnails (78px wide) via `tgen/tobs/tdraw`. The `--scale-factor` CSS var must stay on `.page` (pdf.js text layer needs it). Scale is clamped to 0.1–8; Ctrl-wheel zoom is debounced 60 ms (`wzT`). `openPdf` no longer destroys the previous pdf (it may live in another tab); only `tabClose` destroys. `curN` is the current page: `goto/prev/next` and the arrow keys step from it, `cur()` updates it on scroll; there is no page input or zoom readout any more.
- Keys: `?` the shortcut card (again), `F` find, `K` the document palette, `[`/`]` previous/next tab, `+`/`-`/`0` zoom, `←`/`→` page step, `↑`/`↓`/`Space` scroll, `Home`/`End` first/last, `T` theme, `H` thumbnails, `,` settings, `O` open (plus `⌘O`, which Safari may claim itself), `⌘S` save notes, `⌘⇧S` save PDF with comments, `⌘⇧X` clear all. One keydown handler matches on `e.code` (`Slash`/`Comma`/`KeyT`/`KeyO`/…) so a Chinese IME's full-width punctuation cannot break the shortcuts, skips while `e.isComposing`, and skips events targeted at inputs/buttons.
- Selection: `mouseup` on the viewer → dehyphenate `-\n` before lowercase → collapse whitespace → `lastSel` dedupe → auto-translate if `#mAuto`. Drag&drop is handled at document level and only for files (PDF + notes JSON); `translate(txt)` gets its text from the selection, there is no composer.
- Actions: the object `A` is now called from keys only (`A.open`, `A.theme`, `A.thumbs`; no `data-a` elements remain); theme via `setTheme` + `mrdTheme`, with an inline `<script>` applying it before paint.

## Pitfalls

- `#mViewWrap [hidden]{display:none!important}` keeps hidden cards and the settings sheet hidden against the overlay's rules; `#mSelT [hidden]` likewise. Inline `on*` handlers must not return `false` (it cancels the event) — wrap arrow bodies in braces.
- The word-count line contains literal `\uXXXX` ranges; those can't be matched through the Edit tool (escapes get decoded). Edit that line via python or split edits around it.
- Shortcuts must keep matching on `e.code` as well as `e.key`: with a Chinese IME on, plain keys arrive as full-width characters (`？`, `，`) or as composition; the code check (`Slash`, `Comma`, `KeyT`, `KeyO`) keeps them working, and `e.isComposing` guards composition.
- pdf.js is pinned to 3.11.174: v4 replaced `pdfjsLib.renderTextLayer` with a `TextLayer` class — don't upgrade casually.
- The repo has to stay public: Pages is a branch deploy from `main`, and a private repo drops the site (it went dark 2026-10-10 that way and was re-enabled 2026-10-31).
- DeepSeek receives both `thinking:{type:'enabled'}` and `reasoning_effort`; fine with the current models, revisit if the API rejects them.
- The card classes reuse svguest's chat names (`wt/sh/tm/tk/th/er/dim`); keep them in sync when svguest changes. `MARK` is ocrp's own waiting mark (the translate-arrow glyph, user's request 2026-10-31; it breathes with `mTr`, 17×13 px), not svguest's house.
